# Le besoin : une TodoList

Texte à coller tel quel dans votre agent à l'étape 1.2.

## Ce que dit le client

> Je veux une petite page pour noter mes tâches du jour. Je tape une tâche, elle s'ajoute à la liste. Je coche ce qui est fait, je peux supprimer une tâche, et je veux voir d'un coup d'œil combien il m'en reste. Je veux aussi pouvoir n'afficher que ce qui reste à faire, ou que ce qui est terminé. Si je ferme la page et que je reviens, ma liste doit être encore là. Deux fois la même tâche, ça n'a pas de sens. Et pas de titres à rallonge.

## Ce qui est imposé

- Une page web qui s'ouvre par double-clic : `index.html`, `style.css`, `app.js`.
- HTML, CSS et JavaScript natifs. Aucun serveur, aucune base de données, aucun framework, aucune dépendance, aucun CDN.
- Des scripts classiques, pas de modules ES : ils ne se chargent pas quand la page est ouverte depuis le disque.
- Quatre zones dans la page : la saisie, les filtres, la liste, le compteur.
- Un mode démonstration : avec `?demo` à la fin de l'adresse, la liste est préremplie de trois tâches dont une terminée, et rien n'est enregistré.

## Ce qui reste à trancher

Le client n'a pas tout dit. C'est à vous de décider, pas à l'agent de deviner.
